# Loan Default Prediction & Credit Risk Scoring

Fintech machine learning application predicting credit default probability using Random Forest classification based on Debt-to-Income (DTI), credit score, and income ratios.

## Pre-Trained Weights
Pre-packaged under `model/loan_model.pkl` and `model/scaler.pkl`. Zero student training required.

## Setup Instructions
```bash
python -m venv venv
venv\Scripts\activate   # Windows

pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000`.
